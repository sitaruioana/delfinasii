# Delfinașii

Site educațional pentru foștii Delfinași, clasa a VIII-a.

[Deschide site-ul](https://sitaruioana.github.io/delfinasii/)

HELP: 20 de misiuni (10 × 1 minut, 5 × 2 minute, 5 × 3 minute), punctaj parțial și pașaport.
LLR: Borcanul cu provocări, cu puncte pentru răspunsuri corecte.
Matematică: acces către MatePolis.

Progresul se salvează în browser, separat de Clasa Curajoșilor. Pașaportul poate fi exportat și importat din secțiunea dedicată.
